# v0.0.1

**Released:** 2025-12-25

## Added

- Initial release of histui notification daemon and TUI
- Daemon (histuid) for displaying desktop notifications
- TUI (histui) for browsing notification history
- Theming system with CSS-based customization
- Icon alias system for consistent app icons
- D-Bus integration for notification capture
- Multiple built-in themes
